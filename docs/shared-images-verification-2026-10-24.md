удаляются по завершении.

| Сценарий | Результат |
|---|---|
| Свежие признаки | Прогноз и повторное чтение кеша успешны |
| Низкий CS, отсутствие измерений, ошибка источника | Оба POST прогноза и GET статуса возвращают 503 даже при ранее валидном кеше |
| Просроченная цель | Статус `expired`, `is_usable=false`; прогноз пересчитывается из текущих признаков |
| Недоступен Data API | 502, в том числе при попытке чтения кеша с проверкой активности |
| Недоступна модель | 502; прежний кеш не перезаписывается |

Ошибочные случаи воспроизведены на синтетических данных. Это проверка
программных контрактов, а не оценка точности прогнозов.
