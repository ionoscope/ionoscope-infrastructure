## Preserved data and runtime paths

The old `%LOCALAPPDATA%/Docker` junction pointed to `D:/AppsData/Docker-Local`.
Runtime directory and Unix socket creation through that layout failed repeatedly.
The junction was preserved as `Docker.junction-backup-20261104`. Docker now uses
an ordinary local runtime directory. The original images/container disk remains
on D, attached through the narrower `Docker/wsl/disk` junction. Updated WSL
runtime files and service sockets remain in the local Docker directory.

Both discovered disk sets and the prior settings were copied to
`D:/Проекты/ionoscope/output/docker_repair_20261104`. The main original disk's
SHA-256 matched its backup. Keep these backups until the recovered installation
has been used successfully for a while.

## Application changes

- GIRO's incomplete certificate chain is completed with the official emSign
  cross-certificate in `ionoscope-data/certs`; system roots, hostname checks and
  complete-chain verification are retained.

  observations. The result matched all 24,428 rows in the real catch-up batch.

  and checks the current archive, parameter, explanation and shadow routes.
